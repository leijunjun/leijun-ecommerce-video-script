# 电商带货脚本 / E-commerce Video Script

面向中国大陆电商短视频。以「目标客群 × 使用场景 × 可验证买点」确定创作方向，交付脚本简报、台词和逐镜分镜。

## 安装与使用

1. 下载并解压，把完整的 `leijun-ecommerce-video-script` 目录放进个人 Codex Skills 目录，例如 `~/.codex/skills/`。保留 `SKILL.md`、`agents/` 和 `references/` 的相对路径。
2. 在 Codex 里调用 `$leijun-ecommerce-video-script`，附上商品主图、详情页或已确认的卖点。可补充受众、平台、时长和视频数量。
3. 先确认 Skill 给出的目标客群、买点与证据、分镜结构。确认后，Skill 再输出完整台词和分镜。调整关键方向后，请确认更新的简报。

> 用 `$leijun-ecommerce-video-script` 根据这张老抽详情页，写一条 15 秒带货视频。先给我确认客群、上色买点和分镜结构，再写完整脚本。

## Installation and use

1. Download and extract the archive. Move the complete `leijun-ecommerce-video-script` folder into your personal Codex Skills directory, for example `~/.codex/skills/`. Keep its internal file structure intact.
2. Invoke `$leijun-ecommerce-video-script` with a product image, listing, or verified selling points. Specify the audience, platform, duration, and number of videos as needed.
3. Review and approve the proposed audience, buyer benefit, evidence, and shot outline. The skill writes the full script after you approve the latest brief.

> Use `$leijun-ecommerce-video-script` to plan a 15-second e-commerce video from this dark soy sauce listing. Show me the creative brief first, then write the script after I approve it.
